# Measured: gh 2.46 has no `--slurp`

Date: 2026-09-27. Host: WSL2 Ubuntu, with gh 2.46.0 from Ubuntu's own archive
(`2.46.0-4`), the version `apt` installs there.

| Call | Outcome |
|---|---|
| `gh api --paginate --slurp 'repos/revnix/reeve/labels?per_page=2'` | refused: `unknown flag: --slurp` |
| `gh api --paginate --jq '.[] \| tojson' 'repos/revnix/reeve/labels?per_page=2'` | 9 lines, one item of JSON on each, across 5 pages. The repository has 9 labels. |

What followed:

- `reeve doctor`'s authority baseline (R-13) read the rulesets with
  `--paginate --slurp`, so on this host it could never read the live rules and
  reported UNKNOWN.
- `ghApi` in `src/baseline.mjs` now reads a paged list with
  `--paginate --jq '.[] | tojson'`, one item per line, and doesn't use `--slurp`.
