## Global Constraints

- **Node:** always `~/.nvm/versions/node/v24.17.0/bin/node`. Alias it `N` in every shell: `N=~/.nvm/versions/node/v24.17.0/bin/node`. `node` on PATH is v22 and `node:sqlite` emits an ExperimentalWarning there; CI asserts a floor of 24.
- **Tests:** plain scripts, no framework. Use the `check(ok, name, detail)` helper shape every existing test file uses; `console.log("PASS  name")` / `"FAIL  name"`; end with `process.exit(fail ? 1 : 0)`. New files under `test/` are discovered by CI automatically.
- **The four-check stub loop for every fix:** control green, stub verified applied, the RIGHT assertion red, restore verified **by file copy, never `git checkout`** — `git checkout` restores to the last *commit* and silently discards uncommitted work, which has cost real lines in this repository. Every non-close-out task below names its stub as a **step**, not as a promise here.
- **Run the full suite before every commit**, with the one exclusion the next sentence explains:

  ```bash
  fail=0
  for f in test/*.test.mjs; do
    case "$f" in */escape.test.mjs) continue;; esac    # see below: not while the daemon is live
    $N "$f" >/dev/null || { echo "FAILED $f"; fail=1; }
  done
  # NONZERO on red. `|| echo` turns a failing node process into a SUCCESSFUL
  # command, so this loop exited 0 with any number of red files -- and this is
  # the mandatory pre-commit and close-out gate, so an executor checking the
  # command status commits and publishes a broken implementation on a suite that
  # just failed. The flag is set inside the loop because a pipeline's status is
  # its last command's, and the last command here is `done`.
  [ "$fail" -eq 0 ] || { echo "the suite is RED; do not commit"; exit 1; }
  ```

  The glob must not simply be `test/*.test.mjs`: that includes `escape.test.mjs`, which writes decoys into the shared `~/.reeve/canary/` tree the live daemon reads and probes the login keychain. **The baseline is 93 test files, 0 failures, 5,131 PASS assertions on the content of `16cd880`**, excluding `test/escape.test.mjs`, under `REEVE_HOME` pointing at a directory **literally named `.reeve`**, with the node above. **That is the ONE base every task in this plan is measured against — never a chained comparison against the previous task.** The instrument was controlled before its output was believed: one file alone reports 72 PASS lines, and a deliberately red probe exits 1 and the accumulator sees it.
- **No task in S3 performs any GitHub effect, opens any PR, or enqueues any outbox row of a `gh.*` or `git.push.branch` kind; the switches for those are off and S3 does not change that and must not.** PR-D3 Task 12 asserts it over the whole pipeline, with a positive control.

The measured comparator is **$2.66 for three real dispatches** (`docs/measured/2026-08-23-three-real-dispatches.md`), and that same document had to **withdraw a figure** because run 3 overwrote runs 1 and 2's transcripts by reusing one path. ## The test harness every file in this plan opens with

Where a task writes `/* ... standard harness ... */`, it means exactly this block. It is written once here rather than repeated in each task, but it is **not** optional shorthand: without it `check`, `dir` and the imports are undefined and the file fails before reaching its first assertion.

```js
import { mkdtempSync, rmSync, writeFileSync, readFileSync, existsSync } from "node:fs";
import { tmpdir } from "node:os";
import { join } from "node:path";

let fail = 0;
const check = (ok, name, detail) => {
  console.log(`${ok ? "PASS" : "FAIL"}  ${name}`);
  if (!ok) { if (detail) console.log("        " + detail); fail++; }
};
const dir = mkdtempSync(join(tmpdir(), "reeve-<slug>-"));
```

and closes with:

```js
rmSync(dir, { recursive: true, force: true });
console.log(fail ? `\nfailed=${fail}` : "\nall green");
process.exit(fail ? 1 : 0);
```

Each task names any imports it needs **beyond** these.

**And one fixture every file in this plan reuses**, copied from `test/hub-transition.test.mjs:32-45` because it is already the shape the hub's foreign keys require. Paste it once per test file, below the harness:

```js
// A task, plus a RUN of phase_event rows. `outbox.fence` references
// phase_event(seq), so a fixture with no events fails on the foreign key rather
// than on anything these blocks are about.
const seed = (db, { id, phase, generation = 1, depth = null, sourceKey = null, events = 4 }) => {
  db.prepare(
    `INSERT INTO task(id, project, repo_id, nwo_snapshot, title, phase, generation, depth,
                      source_kind, source_key, repo_path, profile_path, profile_hash,
                      default_branch, visibility, registry_version, created_at, updated_at)
     VALUES(?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,unixepoch(),unixepoch())`)
    .run(id, "p", 1, "o/r", "t", phase, generation, depth, "founder",
         sourceKey ?? `k:${id}`, "/repo", "/profile.json", "hash", "main", "private", 1);
  for (let i = 0; i < events; i++)
    db.prepare(
      `INSERT INTO phase_event(task, at, op, from_phase, to_phase, from_generation, to_generation, detail)
       VALUES(?, unixepoch(), 'phase.advanced', ?, ?, ?, ?, '{}')`)
      .run(id, phase, phase, generation, generation);
};
```

// sizing -- the BUILD_SIZE phase: what it costs, what it may touch, and what it
// is asked.
//
// The budget is stated in the prompt and enforced on the command line. Those are
// two different mechanisms on purpose: the statement is so the worker can plan
// eight minutes of work rather than eighty, and the enforcement is --max-turns
// and --max-budget-usd, which the CLI applies whether the worker read the prompt
// or not. A worker that checks its own budget is a worker that can skip the
// check.
//
// The model and the effort are deliberately ABSENT from the prompt. They are
// dispatcher facts, recorded in the contract snapshot, and a second copy in
// prose is a second copy that can disagree with the first.
const DEFAULTS = Object.freeze({ maxBudgetUsd: 1.5, maxAttempts: 3 });

export const SIZING_SPEC = Object.freeze({
  action: "BUILD_SIZE",
  phase: "SIZING",
  budgetMinutes: 8,
  maxTurns: 15,
  model: "sonnet",
  effort: "low",
  allowedTools: "Read,Grep,Glob",
  network: "none",
  product: "sizing.json",
});

export function sizingBudget(profile) {
  const declared = profile?.builder?.budgets?.BUILD_SIZE ?? {};
  return {
    budgetMinutes: declared.budgetMinutes ?? SIZING_SPEC.budgetMinutes,
    maxTurns:      declared.maxTurns      ?? SIZING_SPEC.maxTurns,
    model:         declared.model         ?? SIZING_SPEC.model,
    effort:        declared.effort        ?? SIZING_SPEC.effort,
    maxBudgetUsd:  declared.maxBudgetUsd  ?? DEFAULTS.maxBudgetUsd,
    maxAttempts:   declared.maxAttempts   ?? DEFAULTS.maxAttempts,
  };
}

/** The two limits every later phase sizes against. Defaults are section 8.2's. */
export function reviewability(profile) {
  return {
    maxWeightedFiles: profile?.builder?.budget?.maxWeightedFiles ?? 10,
    maxPackages:      profile?.builder?.budget?.maxPackages ?? 2,
  };
}

export function sizingPrompt({ task, territory, budget, review }) {
  const claims = territory.map(t => `  - ${t}`).join("\n");
  return [
    `You are sizing one task. Read only; you have Read, Grep and Glob and no network.`,
    ``,
    `Task ${task.id}: ${task.title}`,
    task.body ? `\n${task.body}\n` : ``,
    `Declared territory:`,
    claims,
    ``,
    `Your budget is ${budget.budgetMinutes} minutes and ${budget.maxTurns} turns. Plan inside it;`,
    `a partial answer inside the budget beats a complete one that is cut off.`,
    ``,
    `Size against a reviewability budget of ${review.maxWeightedFiles} weighted changed files`,
    `per slice and at most ${review.maxPackages} packages touched.`,
    ``,
    `Emit sizing.json exactly as the output schema requires. BLOCKED or INFEASIBLE with a`,
    `reason is a success outcome; salvage is not.`,
  ].join("\n");
}

```js
// The floors. Code, not prompt, and applied AFTER the report -- the model
// proposes, code disposes. A classifier asked to police itself is a gate that
// can be argued with, and a noisy gate is also an insensitive one.
//
// Each floor states the sentence the spec renders, so the founder reads why a
// depth is what it is rather than inferring it from a number.
const ORDER = Object.freeze(["trivial", "standard", "deep"]);
const raiseTo = (have, want) => (ORDER.indexOf(want) > ORDER.indexOf(have) ? want : have);
const intersects = (territory, riskPaths) =>
  territory.some(t => riskPaths.some(r => t.startsWith(r) || r.startsWith(t)));

export const FLOORS = Object.freeze([
  Object.freeze({
    id: "risk-territory",
    why: "the territory intersects a path the profile declares risky",
    exemptScout: true,
    fires: ({ report, territory, profile }) =>
      intersects(territory, profile?.builder?.risk?.paths ?? []) ||
      (report.risk_paths_touched ?? []).length > 0,
    raise: { depth: "standard" },
  }),
  Object.freeze({
    id: "package-span",
    why: "the territory spans more packages than the conceptual-surface budget",
    exemptScout: false,
    fires: ({ report, packages, review }) =>
      Math.max(packages.length, report.est_packages ?? 0) > review.maxPackages,
    raise: { depth: "standard", minSlices: 2 },
  }),
  Object.freeze({
    id: "weighted-files",
    why: "the estimated weighted file count exceeds the reviewability budget",
    exemptScout: false,
    fires: ({ report, review }) => (report.est_weighted_files ?? 0) > review.maxWeightedFiles,
    raise: { depth: "standard", minSlices: 2 },
  }),
]);

// A LEDGER label, keyed on the only column that stores one today. `task` has no
// `kind` and no label column, and the stage adds no column; `source_key` is
// written from the filing and is the whole of what a scout task can be
// recognised by. The exemption is narrow on purpose: waiving the risk floor for
// a verification task is the case section 5 names, and waiving the size floors
// too would let a filing buy a `trivial` on a ten-package change by its name.
const isScout = (sourceKey) => /^scout-/.test(sourceKey ?? "");

/**
 * Bind the classifier's proposal. Returns the depth that will be persisted, the
 * slice minimum, and every floor that fired or was waived -- the waiver is
 * recorded because "no floor fired" and "a floor was waived" are different
 * facts and only one of them is a reason to look again.
 */
export function applyFloors(report, { profile, territory, packages, sourceKey }) {
  const review = reviewability(profile);
  const scout = isScout(sourceKey);
  let depth = report.depth;
  let est_slices = report.est_slices ?? 1;
  const floors = [];
  for (const floor of FLOORS) {
    if (!floor.fires({ report, territory, packages, profile, review })) continue;
    if (scout && floor.exemptScout) { floors.push("scout-exempt"); continue; }
    floors.push(floor.id);
    depth = raiseTo(depth, floor.raise.depth);
    if (floor.raise.minSlices) est_slices = Math.max(est_slices, floor.raise.minSlices);
  }
  return { depth, est_slices, floors, proposed: report.depth };
}
```

// cited one. An empty Findings section is refused rather than passed -- a

const CITATION = /`[^`\s]+:\d+`/;
function researchFindings(text, expect) {
  const section = text.split(/^##\s+/m).find(s => /^Findings/i.test(s)) ?? "";

/**
 * The DESIGN prompt.
 *
 * The prior artifact is inlined in FULL, never summarised: a summary of a
 * summary is how a fact loses the citation that made it checkable. On the
 * trivial path there is no research.md at all, so the prompt asks for a short
 * measured-context section instead -- an absent research phase must leave a
 * visible stand-in, not a gap that reads months later as a lost phase.
 */
export function designPrompt({ task, depth, budget, review, research }) {
  const lines = [
    `You are designing one task. Read only, no network; you have the repository and subagents.`,
    ``,
    `Task ${task.id}: ${task.title}`,
    ``,
    `Your budget is ${budget.budgetMinutes} minutes and ${budget.maxTurns} turns.`,
    `Slice against a reviewability budget of ${review.maxWeightedFiles} weighted changed files`,
    `and at most ${review.maxPackages} packages per slice. Where a slice must exceed it, declare`,
    `an atomicity exception with its justification.`,
    ``,
  ];
  if (depth === "trivial")
    lines.push(
      `This task was sized trivial and no research phase ran. Open design.md with a short`,
      `"## Measured context" section: what you checked, the command you checked it with, and`,
      `what it returned. It stands in for the research.md that is absent.`, ``);
  else
    lines.push(`The research phase produced this. Use it; do not re-derive it.`, ``, research, ``);
  lines.push(
    `Emit design.md with a "## Slices" section. Each slice states a title, its expected files`,
    `with their weighted count, the packages it touches, its test plan, and a done-condition`,
    `written as a command in a fenced block. BLOCKED or INFEASIBLE with a reason is a success`,
    `outcome; salvage is not.`);
  return lines.join("\n");
}
